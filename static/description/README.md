# Acopios de Materiales (Customer Material Deposits)

## Ícono del Módulo

El archivo `icon.png` debe estar en esta carpeta (`static/description/`).

**Especificaciones recomendadas:**
- Tamaño: 94x94 píxeles
- Formato: PNG con fondo sólido
- Estilo: Ícono blanco minimalista sobre fondo oscuro (ej. #714B67)
- Diseño: Representación de acopio/almacén (cajas apiladas, estanterías)

Si el ícono no está presente, Odoo usará el ícono por defecto del módulo.
